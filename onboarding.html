SECTION 02
플랫폼 개념
바다이야기가 무엇을 해결하며 왜 만들어졌는지 이해합니다.
🌊

해양 특화

선원·연구자·수산 전문가가 자신의 전문성을 출판하고 독자와 연결되도록 설계했습니다.

📡

오프라인 우선

인터넷이 없는 바다 위에서도 완전히 작동합니다. 이야기는 로컬에 저장되고 입항 시 자동 동기화됩니다.

📚

출판 파이프라인

이야기도서 → 이야기선정 → 출간도서. 독자 반응이 편집 선정을 이끕니다.

🪙

포인트 경제

모든 활동이 포인트를 적립합니다. 포인트로 도서를 교환하거나 할인받고 크루 등급을 올립니다.

⚓

크루 커뮤니티

선박 승무원을 모티프로 한 3개 부서 × 8단계 등급제. 최고 등급은 에이콘 공식 협력 저자입니다.

🔗

퍼블리셔 연동

저자가 에이콘 내부 시스템과 계정을 연동해 원고 진행과 인세 대시보드를 실시간으로 확인합니다.

SECTION 08
기술 아키텍처
빌드 도구 없는 단일 HTML 파일 — 오프라인으로 작동하고 연결 시 클라우드와 동기화됩니다.
📄

단일 파일 HTML PWA

HTML·CSS·JS를 한 파일에. 설치 없이 URL로 접속. PWA 매니페스트로 설치형 앱으로도 동작.

📡

오프라인 우선 (로컬스토리지 + 아웃박스)

모든 입력을 즉시 로컬스토리지에 저장. 인터넷 감지 시 클라우드로 자동 동기화.

🗺️

GPS + 카메라 API

watchPosition()으로 실시간 좌표 추적. 카메라 API로 사진/영상. 모든 게시물에 자동 태깅.

🎮

HTML5 Canvas2D 게임

낚시왕: DOM 애니메이션. 오션 카지노: Canvas2D 물리 엔진(공·핀·슬롯). 포인트 자동 적립.

🔐

클라우드 백엔드

PostgreSQL DB · 인증 · 실시간(채팅) · 스토리지(파일). RLS로 모든 사용자 데이터 보호.

⚙️

GitHub Pages + Actions

main 푸시 시 자동 배포. GitHub Secrets로 클라우드 키 주입. 서버 비용 0원.
