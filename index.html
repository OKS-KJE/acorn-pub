전략 3축
📖
기본 중시 — 출판 업무 충실
기획·편집·제작·유통의 핵심 출판 역량을 지속 강화합니다. 저자 발굴부터 독자 도달까지 전 과정의 품질을 높이며 출판의 기본기를 절대 놓치지 않습니다.
🤖
AX — 출판 관련 AI 무기 장착
시대 변화를 반영한 AI 도구를 실무에 적극 도입합니다. 원고 교정·메타데이터 생성·키워드 추천·홍보문안·판매 분석까지 AI로 경쟁력을 높입니다.
🌐
글로벌화 — 출판 사업의 입체화
출판업 기반의 입체적 시각으로 플랫폼 사업(Publisher-On·Author-On·Reader-On)과 Amazon KDP 글로벌 유통 사업으로 확장하여 수익 다각화와 글로벌 기업화를 실현합니다.

플랫폼구분역할 및 내용
📋 Publisher-On 출판사 플랫폼 출판 운영 전 과정 디지털화 및 표준화. 기획 승인·원고 관리·편집 일정 추적·비용 산정·판매 분석·정산 관리를 하나의 시스템으로 연결. 향후 외부 출판사 대상 B2B 솔루션 확장 가능.
✍️ Author-On 저자 플랫폼 저자 맞춤형 출판 서비스 — 원고에서 IP 사업화까지. 완전 자비출판·반기획출판·기획출판·KDP 대행 모두 지원. 저자의 원고를 실제 판매 가능한 IP로 발전시키는 출판 파트너.
📖 Reader-On 독자 플랫폼 종이책 + 디지털 콘텐츠 통합 유통 허브. 전자책·오디오북 통합 유통, 독자 데이터와 커뮤니티를 기반으로 개인화된 지식 경험 제공.
🌐 Amazon KDP 글로벌 유통 국내 저자의 콘텐츠를 글로벌 시장으로 연결. Amazon KDP를 통해 10개국 이상·45개 언어권 독자에게 전자책·POD 형태로 유통. 저작권을 보유한 채 글로벌 시장에 진입하는 원스톱 대행 서비스.

Step 1
Import — 콘텐츠 가져오기 또는 Wordgenie로 시작

콘텐츠를 가져오는 방법은 4가지입니다. 빠른 결과물의 핵심은 원본 콘텐츠 품질입니다 — Word나 Google Docs에서 가져올 경우 서식이 올바른지 먼저 확인하세요.

📄 텍스트 기반 가져오기
  • Webpage URL — 웹페이지 주소 직접 입력
  • MS Word (.docx) — 서식 확인 후 업로드
  • Google Docs — 구글 문서 연동
  • PDF — 기존 PDF 변환
🤖 Wordgenie AI — 콘텐츠가 없을 때

처음부터 시작한다면 Wordgenie AI가 주제·키워드로 초안을 자동 생성합니다.

▶ Wordgenie 시작 영상 ↗

Word 서식 가이드: docx 가져오기 전 Word 파일 서식 설정 방법을 먼저 확인하세요.

Step 2
Draft 검토 — 자동 저장 초안 편집

콘텐츠를 가져오면 왼쪽 메뉴 DOCs 섹션에 자동으로 Draft가 저장됩니다. 디자인 편집기로 넘어가기 전에 이 단계에서 내용을 검토하고 수정하세요.

💾
